# i18n

> 英文 signature-only 版本（仅函数 / 类签名速查）：[`docs/api/i18n.md`](../api/i18n.md)

后端轻量 i18n 模块：根据请求语言返回本地化字符串。

## 函数

### `normalize_lang(raw: str) -> str`

将语言标识归一化为支持的语言代码。

### `detect_request_lang() -> str`

从 Flask request 的 Accept-Language 头检测语言，回退到 config.toml 配置。

### `get_locale_message(key: str, lang: str | None = None) -> str`

获取本地化消息字符串。
